# Connector thumbnail

`public/screenshot.jpeg` is the 1200 × 630 Sites deployment thumbnail. Keep it in the build and deployment archive. The title hierarchy is Freesound Connector, followed by a smaller "by Song Machines". It adds no interactive interface to the connector and is separate from the plugin listing icon.

The artwork is a variation of the Song Machines robot-workshop banner supplied by the project owner. It was made with the built-in OpenAI image-generation tool on 2026-10-08, then sized and encoded as JPEG for deployment.

Generation brief: "Preserve the cinematic Song Machines robot workshop. Recompose for a 1200 × 630 thumbnail. Feature the Freesound waveform wordmark and large CONNECTOR as the primary identity, with smaller by Song Machines beneath. Keep the robot character, warm workbench lighting, and readable text at small size. No app controls or additional slogan."

Freesound wordmark reference: [official MTG/Freesound logo asset](https://github.com/MTG/freesound/blob/master/freesound/static/bw-frontend/public/logos/logo-text-white.svg). The raster artwork contains a generated rendering of that reference; it is not an official Freesound product badge or endorsement. The Freesound name and mark belong to their respective owners. This project is independently maintained by Song Machines.

Future releases should reuse this bundled asset unless the user asks for a branding change. Do not replace it with a screenshot of the connector's JSON homepage, and do not regenerate it for each person's installation.
